# Quick Draw categories (345 classes)

Synced from [Google Creative Lab `categories.txt`](https://raw.githubusercontent.com/googlecreativelab/quickdraw-dataset/master/categories.txt).

- `categories.txt` — one label per line (source of truth for prompts)
- `categories.json` — same labels as a JSON array for the app and model tester

Game prompts and the ml5.js DoodleNet recognizer both use this label set.
